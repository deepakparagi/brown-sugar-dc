# ☕ Brown Sugar Fusion Cafe

![Brown Sugar Banner](/public/Images/Brown%20Sugar%20Fusion%20Cafe%20Logo.png)

A truly **premium, elite-tier digital experience** crafted for Brown Sugar Fusion Cafe. Designed with cinematic 3D parallax effects, high-end editorial typography, and seamless mobile interactions, this web application pushes the boundaries of modern cafe web presence. 

Designed & Developed by **DeepCipher Agency**.

## 🌟 Key Features
- **Cinematic 3D Parallax Environments:** Utilizes `@react-three/fiber` to render abstract, moody, cafe-inspired 3D scenes (Dark Monoliths, Copper Espresso Machines, Floating Bronze Mirrors) that react smoothly to user mouse movements.
- **Flawless Mobile Experience:** Full edge-to-edge UI with custom frosted-glass swipeable image carousels built heavily atop `swiper.js`, engineered for absolute fluidity on mobile.
- **Editorial Typography:** Driven by luxurious Google Fonts—`Playfair Display` for bold, impactful headings, and the geometric `Montserrat` for tracked-out, premium credits and metadata.
- **Performance Optimized:** Uses Vite as the build tool to ensure blazing fast hot-reloads locally and perfectly minified production bundles, completely bypassing bloated 3D or Icon libraries.

## 🚀 Tech Stack
- **Framework:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** TypeScript
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **3D Engine:** [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction) & [@react-three/drei](https://github.com/pmndrs/drei)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Carousels:** [Swiper](https://swiperjs.com/)

## 🛠️ Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```

## ☁️ Vercel Deployment Guide

This project is pre-configured and ready for one-click deployment to **Vercel**.

1. Connect this repository to your Vercel account.
2. Vercel will automatically detect the **Vite** framework.
3. The default settings will work perfectly:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Deploy!

*Note: A `vercel.json` file is included to ensure correct SPA routing fallback.*
